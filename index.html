Data source and methodology
River geometry: OpenStreetMap waterway features, or a user-uploaded river-centreline dataset.

Discharge: Open-Meteo Flood API using Copernicus GloFAS model output. The nearest available model grid cell may differ from the requested coordinates.

Flow animation: Particles are interpolated along the retrieved river polyline. Their movement is illustrative and does not represent observed water speed or a calibrated hydraulic simulation.

Settlements: OpenStreetMap place features supplemented with named reference locations. Reference coordinates are approximate.
Data providers: OpenStreetMap contributors • Open-Meteo • Copernicus GloFAS
