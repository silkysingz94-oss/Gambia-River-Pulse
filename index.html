05. Upload external observation CSV

Required columns: date, discharge_m3s. Optional columns: station, water_temp_c, water_level_m, salinity_ppt, longitude, latitude, source and data_type. Uploaded records are kept separate from the five GloFAS API query results.

06. Data limitations

• GloFAS provides modelled river discharge in m³/s.
• Water temperature, water level and salinity are not supplied by this discharge request.
• Empty optional fields are not estimated or invented.
• OSM settlement completeness depends on mapped coverage.
• Approximate settlement coordinates are reference locations, not surveyed riverbank positions.

06. Methodology

River geometry is retrieved from OpenStreetMap waterway features. Connected river segments are joined by matching their endpoints. The animation calculates cumulative distance along the actual geographic polyline and interpolates each moving particle between consecutive river vertices. Therefore, particles follow the mapped river's bends and curves.

GloFAS daily discharge is retrieved from the Open-Meteo Global Flood API. Five query locations are retained for comparative analysis. The API response grid coordinates are stored separately from the requested coordinates.
